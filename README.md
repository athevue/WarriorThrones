# Warrior Thrones: Bathroom Rating App

Features:
- Add Bathroom: Form with rating categories, amenities, and location; validation included
- Browse Bathrooms: List/grid view, search, filter, sort, and summary cards
- Ratings & Amenities: Cleanliness, smell, privacy, accessibility, lighting, ventilation, noise, safety, supplies, and amenities

Tech Stack
- React / Next.js
- Node.js / Express
- Supabase / PostgreSQL
- Custom UI components


Installation
- git clone <repo-url>
- cd bathroom-ratings-app
- npm install
- npm run dev
